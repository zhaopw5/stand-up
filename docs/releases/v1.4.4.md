修复 Windows 本机构建时可能错误打包其他工具同名 DLL，导致 QtCore 导入失败的问题。

- Windows 打包使用受控的 DLL 搜索路径，避免将 PDF 等工具的 ICU 库混入应用。
- 启动验证必须由应用成功加载 Qt、创建主窗口并进入事件循环后主动报告成功，再正常退出；仅有存活进程不再视为通过。
- 保留 v1.4.3 的蓝牙耳机和默认音频输出自动切换修复。

Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64 和 Ubuntu x86_64 同一提交构建、验证后统一发布。
Windows 未数字签名；macOS 仍为预览版，未使用 Developer ID 签名或 Apple 公证，首次启动请参阅 docs/MACOS.md。
自动检查验证程序启动与音频路由逻辑；实际蓝牙耳机的可听效果仍需实机体验。
