修复 Ubuntu GNOME Wayland 下切换迷你浮窗后窗口消失的问题，并补齐 Linux 发布包。

- Linux 在有 X11 显示连接且未显式选择 Qt 后端时优先使用 XWayland（xcb）。
- 从最大化窗口进入小窗前退出最大化，恢复时还原原状态。
- Linux 包补齐窗口图标，修正资源检查路径，并提供独立 Linux 使用说明。
- 新增 Windows x64 构建检查及普通/最大化窗口的小窗回归测试。
- 四个平台包均由同一提交构建；全部构建和自动检查通过后才统一发布。

下载：
- Windows 10/11 x64：stand-up-windows-x64.zip
- Ubuntu 24.04 x86_64：stand-up-linux-x86_64.tar.gz
- macOS 13+ Apple Silicon：stand-up-macos-arm64.zip
- macOS 13+ Intel：stand-up-macos-x86_64.zip

验证范围：
- Windows：GitHub Windows runner 上执行界面、小窗回归测试及打包 EXE 启动检查；本次尚未在作者的 Windows 电脑上人工复测。
- Ubuntu：自动界面与小窗回归测试、打包程序离屏启动检查；作者已在自己的 Ubuntu GNOME Wayland 桌面确认小窗问题解决。
- macOS：两种原生架构 runner 上执行现有交互测试、构建、签名完整性及应用启动检查。仍为预览版，尚未使用 Developer ID 签名或 Apple 公证。
- 自动测试不代表实际扬声器声音、多屏、休眠恢复和所有机器均已验证。

Windows 包仍未数字签名；macOS 首次打开请按仓库 docs/MACOS.md 操作。不要全局关闭 Gatekeeper。Linux 包不会修改显卡驱动。
