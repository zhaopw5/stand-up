新增 stand up 安卓试用版，保留电脑版的简洁风格、图标及内置音乐。

- Android 8.0 及以上：15/30/45/60 分钟快捷计时、自定义 1–999 分钟、暂停、继续、重置。
- 系统定时提醒、通知栏倒计时与锁屏通知；到时暂停应用音乐并播放一次轻柔提示音。
- 内置《慢步》、导入本地音频、进度控制、顺序和循环播放，支持后台音乐与锁屏控制。
- 离线运行，无账号，无悬浮窗。使用前需要允许通知和准确提醒；静音、勿扰、厂商省电限制仍由手机系统控制。
- 手机重启后请重新开始计时；强行停止后需要重新打开应用。

安装包：安卓选 `stand-up-android.apk`。Redmi K70 Pro / Android 16 的安装和锁屏检查说明见仓库 `docs/ANDROID.md`。

Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64、Ubuntu x86_64 与安卓从同一提交构建，通过检查后统一发布。电脑版功能保持 v1.4.4 的已发布状态。

Windows 未数字签名；macOS 仍为预览版，未使用 Developer ID 签名或 Apple 公证，首次启动请参阅 `docs/MACOS.md`。安卓 APK 使用独立发布密钥签名，尚未在应用商店上架。

自动验证覆盖计时逻辑、静态检查、模拟器及各桌面包启动。Redmi 真机的锁屏提醒、省电设置和可听音效仍需实机体验。
