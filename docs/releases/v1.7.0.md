- Android 新增山野锁屏倒计时卡片，保留原有手机锁屏；无须播放音乐。
- 运行数字由系统持续倒计时；暂停后显示固定剩余时间。展开卡片可暂停或继续，到时保留一次提醒音及「知道了」。
- 旧卡片按钮不能影响新一轮计时；结束或重新开始清除旧卡片。
- 提醒设置新增「锁屏倒计时卡片」类别状态和系统设置入口。沿用「计时状态」类别，保留用户的通知和锁屏隐私选择；部分系统会折叠或隐藏静默卡片。

支持 Android 8.0 及以上，沿用原签名，可覆盖安装 v1.6.2。没有全屏提醒、锁屏替换、悬浮窗或息屏常亮权限。
Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64、Ubuntu x86_64 和 Android 在同一版本构建验证后统一发布。桌面功能沿用已发布版本。
Windows 未数字签名；macOS 仍为试用版，未使用 Developer ID 签名或 Apple 公证，首次启动见 docs/MACOS.md。

自动检查和 Android 16 模拟器不能替代 Redmi 真机的锁屏设置、省电策略、实际音效与 TalkBack 语音体验。
