# 安卓试用版

支持 Android 8.0 及以上。首次版本为 1.5.0，安装包 `stand-up-android.apk` 与 Windows、两种 Mac 和 Linux 包在同一 GitHub Release 提供。

## 安装与开始

1. 在手机上打开仓库 Releases，下载 `stand-up-android.apk`，点击文件安装。系统询问时允许此次安装来源安装应用。
2. 打开 stand up，按应用提示开启通知及“闹钟和提醒”（准确提醒）权限。
3. 选择 15、30、45、60 分钟，或输入 1–999 的整数分钟，再点击开始。
4. 暂停后继续会保留剩余时间；重置使用当前输入时长。
5. 到时会暂停本应用的背景音乐，发出一次轻柔提示音并显示休息通知。确认提醒不会自动恢复音乐。

无需注册或联网。第一版不包含浮窗和手机/电脑同步。通知声音、锁屏是否显示内容、静音和勿扰行为以系统设置为准；应用不会绕过系统限制。

## Redmi K70 Pro / Android 16

首次安装后，先用 1 分钟做一次实际检查：开始计时后锁屏，确认到时能收到声音和通知。然后再试切换至微信等其他应用。

如果没有提醒，先查看应用内的通知及准确提醒权限提示。再在手机的应用管理中找到 stand up，检查通知允许、锁屏通知以及后台/省电限制。不同 HyperOS 版本的名称可能不同，以手机显示为准；必要时允许应用后台运行，并在可用时把该应用的省电策略设为无限制。

“强行停止”会让安卓取消应用的后台工作，需要重新打开应用。手机重启后，上一次倒计时会取消，请重新开始。普通切换应用、锁屏或界面重新创建不应重置倒计时。

## 音乐

内置《慢步》，也可通过系统文件选择器导入音频。选中歌曲后播放，支持进度拖动及顺序、单曲循环、列表循环。只访问你选中的文件，不读取全部存储空间。

文件被移动、删除、云端不可用或含 DRM 保护时可能无法播放，重新导入可访问的文件即可。通知栏和锁屏可控制音乐；摘下有线/蓝牙耳机或其他应用取得音频焦点时，遵守系统音频行为。

## 开发与签名

独立工程位于 `android/`。需要 JDK 17、Android SDK 36 及 Build Tools 36.0.0。

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintRelease assembleRelease
```

生成的 release APK 默认未签名。使用 `scripts/build_android.ps1`，指定私有 keystore 与密码文件签名；或通过 GitHub Actions 中的 `ANDROID_RELEASE_KEYSTORE`（PKCS12 的 Base64）与 `ANDROID_RELEASE_PASSWORD` 两个仓库 secrets 构建。密钥 alias 为 `stand-up`。密钥及密码不得提交到仓库。

后续覆盖安装必须使用同一签名密钥，请备份私有密钥。CI 会运行计时单元测试、静态检查、安卓 16 模拟器测试和 APK 签名校验。模拟器检查不等同于 Redmi 真机、省电策略及可听音效验证。
