# 安卓试用版

支持 Android 8.0 及以上。1.6.0 采用新的计时首页、音乐面板和休息页，可覆盖安装 1.5.0。安装包 `stand-up-android.apk` 与 Windows、两种 Mac 和 Linux 包在同一 GitHub Release 提供。

## 安装与开始

1. 在手机上打开仓库 Releases，下载 `stand-up-android.apk`，点击文件安装。系统询问时允许此次安装来源安装应用。
2. 选择 15、30、45、60 分钟，或通过“自定义”输入 1–999 的整数分钟，再点击“开始专注”。
3. 首次开始且缺权限时会说明通知和准确提醒的用途。可以设置权限，也可以先开始；准确提醒未允许时后台提醒可能延迟。
4. 运行中主按钮为“暂停计时”，暂停后为“继续专注”。继续保留剩余时间；“重新开始”使用所选时长。结束本轮和重新开始前会要求确认。
5. 到时会暂停本应用的音乐，发出一次轻柔提示音并显示休息通知。回到应用可看到休息页，点击“知道了”回到待开始，不自动计时或恢复音乐。

首页的设置入口可打开提醒说明；权限已允许时，首页不再显示权限提示卡。手机重启后的取消计时说明可以关闭。

无需注册或联网。第一版不包含浮窗和手机/电脑同步。通知声音、锁屏是否显示内容、静音和勿扰行为以系统设置为准；应用不会绕过系统限制。

## Redmi K70 Pro / Android 16

首次安装后，先用 1 分钟做一次实际检查：开始计时后锁屏，确认到时能收到声音和通知。然后再试切换至微信等其他应用。

如果没有提醒，先查看应用内的通知及准确提醒权限提示。再在手机的应用管理中找到 stand up，检查通知允许、锁屏通知以及后台/省电限制。不同 HyperOS 版本的名称可能不同，以手机显示为准；必要时允许应用后台运行，并在可用时把该应用的省电策略设为无限制。

“强行停止”会让安卓取消应用的后台工作，需要重新打开应用。手机重启后，上一次倒计时会取消，请重新开始。普通切换应用、锁屏或界面重新创建不应重置倒计时。

## 音乐

首页显示当前曲目和播放/暂停。点击“背景音乐播放列表”打开底部面板，在里面切换曲目、拖动进度、选择顺序/单曲/列表循环，以及导入、排序或移除歌曲（包括内置音乐）。

内置《慢步》，也可通过系统文件选择器导入音频。只访问你选中的文件，不读取全部存储空间。

文件被移动、删除、云端不可用或含 DRM 保护时可能无法播放，重新导入可访问的文件即可。通知栏和锁屏可控制音乐；摘下有线/蓝牙耳机或其他应用取得音频焦点时，遵守系统音频行为。

## 开发与签名

独立工程位于 `android/`。需要 JDK 17、Android SDK 36 及 Build Tools 36.0.0。

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintRelease assembleRelease
```

生成的 release APK 默认未签名。使用 `scripts/build_android.ps1`，指定私有 keystore 与密码文件签名；或通过 GitHub Actions 中的 `ANDROID_RELEASE_KEYSTORE`（PKCS12 的 Base64）与 `ANDROID_RELEASE_PASSWORD` 两个仓库 secrets 构建。密钥 alias 为 `stand-up`。密钥及密码不得提交到仓库。

后续覆盖安装必须使用同一签名密钥，请备份私有密钥。CI 会运行计时单元测试、静态检查、安卓 16 模拟器测试和 APK 签名校验。模拟器检查不等同于 Redmi 真机、省电策略及可听音效验证。

## v1.6.1 山野主题

暂停时，「当前轮剩余」是继续后的时间，「下一轮时长」只影响新一轮；更改预设不会重置暂停轮次。背景音乐播放列表中的三个播放模式始终可见，浅绿色表示当前选择。

## v1.6.2 播放列表管理

每首歌曲提供「上移」「下移」和「移除」，列表顺序在重启后保留。移除不删除手机里的文件；内置音乐也能移除，并可用「恢复内置音乐」重新加入列表末尾。移动当前曲目保留播放进度和播放/暂停状态；移除当前曲目后选择下一首（末尾则选前一首），并暂停。空列表可以继续导入或恢复内置音乐。

## v1.7.0 锁屏倒计时卡片

开始或暂停计时后，不播放音乐也会出现独立的山野倒计时通知。保留手机原有锁屏；展开通知可「暂停」或「继续」，到时可「知道了」。暂停保留本轮剩余时间，结束或重新开始会移除旧卡片。运行中的数字由 Android 系统计时，不需要应用每秒刷新通知。

在「提醒设置 → 锁屏倒计时卡片 → 打开卡片通知设置」中允许原有的「计时状态」通知类别，并允许系统锁屏通知及内容显示。应用保留你的类别开关和隐私选择，不绕过锁屏。系统可能折叠、隐藏静默通知，或只显示图标；具体取决于 Android / HyperOS 设置，不能保证每台手机锁屏都展示完整卡片。音乐通知仍由系统媒体控件管理。

不申请全屏提醒或悬浮窗权限，不替换锁屏，也不提供息屏常亮画面。Android 16 模拟器验证不等于 Redmi 真机锁屏、省电策略和实际音效验证。
