安卓界面按重设计报告更新：首页聚焦计时，把曲库和权限说明移到按需打开的面板与页面。

- 新的低饱和绿色视觉体系，统一圆角、按钮、间距和矢量图标；首页保留倒计时、主要动作和音乐摘要。
- 待开始、计时中、暂停、到时分别显示明确的操作。结束本轮或重开前需要确认；暂停后继续保留原剩余时间。
- 自定义 1–999 分钟使用输入面板，快捷时长选择后立即更新待开始时间。
- 音乐库、导入、播放模式和进度放进底部面板，保留后台播放及系统媒体控制。
- 到时显示休息页，确认后回到待开始；不自动开始下一轮，也不自动恢复音乐。
- 仅缺少权限时显示首页提示，提供通知频道、准确提醒的设置入口；重启说明可关闭。

安卓支持 Android 8.0 及以上。沿用原签名，可覆盖安装 v1.5.0。安装说明见 `docs/ANDROID.md`。

Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64、Ubuntu x86_64 和 Android 在同一版本构建验证后统一发布。桌面功能沿用已发布版本。
Windows 未数字签名；macOS 仍为试用版，未使用 Developer ID 签名或 Apple 公证，首次启动见 `docs/MACOS.md`。

自动检查和模拟器验证不能替代 Redmi 真机的省电策略、实际音效与 TalkBack 语音体验。安装后建议设置 1 分钟并锁屏检查提醒。
