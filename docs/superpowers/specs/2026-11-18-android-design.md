# stand up 安卓第一版

用户已于 2026-11-18 确认本设计范围：安卓、无浮窗、通知栏和锁屏提醒。

## 产品范围
- 原生安卓应用，Android 8.0（API 26）及以上；中文竖屏优先，也适配横屏与大字体。
- 复用电脑版图标、内置《慢步》和六音符提示音，延续灰白简洁风格。
- 15/30/45/60 分钟快捷选择，1–999 整数分钟输入；开始、暂停、继续、重置。
- 同一时刻只有一个计时。暂停保留剩余时间，继续不采用新输入；重置采用输入时长。
- 使用 elapsedRealtime 的截止时间计算剩余时间，防止休眠、界面销毁、修改系统时间造成倒数漂移。
- AlarmManager 在后台触发到时提醒；通知可在锁屏显示。通知/准确提醒权限不可用时显示明确说明，不能假装已可靠安排。
- 到时先暂停本应用音乐并保留进度，再播放系统通知提示音；不自动恢复音乐。手机使用一次提示音及持续显示的通知，不强制全屏，也不承诺绕过静音或勿扰。
- 提醒可确认或点击返回应用。通知栏显示计时状态；运行中使用系统倒计时显示，不靠常驻服务每秒刷新。
- 内置音乐、系统文件选择器导入音频、多曲目选择、进度拖动、播放/暂停、顺序/单曲/列表循环、移除曲目。选择器取得持久 URI 读取权限，不申请读取全部文件的权限。
- 音乐用 Media3 MediaSessionService，支持锁屏播放控制和音频焦点；导入失败或文件丢失给出错误。
- 计时状态及曲目本地保存；手机重启后取消上次计时并明确提示重新开始，避免旧单调时钟截止值被当作新计时。
- 离线运行，无账号、同步、联网、悬浮窗权限。

## 结构与边界
`android/` 为独立 Gradle 工程，Kotlin + Android 原生界面 + Media3。
- TimerState：无安卓依赖的计时状态机，提供 start/pause/reset/remaining/finishIfDue，使用注入的单调时间。
- TimerRepository：SharedPreferences 保存状态，按 boot count 检查重启，串行协调状态与系统闹钟。
- AlarmScheduler / ReminderReceiver / Notifications：安排与撤销同一个 PendingIntent，校验代次与到期状态，避免旧提醒串入新计时。
- MusicService / MusicLibrary：后台播放器、持久曲目和 URI 授权、MediaSession 控制。
- MainActivity：原生可滚动单页，顶部标题、倒计时卡片、时长选择、操作、提醒权限说明和音乐区。

## 验收与发布
先运行纯 Kotlin 状态机测试，覆盖暂停后继续、延迟回调、重置后旧提醒、整数边界、时间显示；再进行安卓 lint、release 构建、签名校验、模拟器安装/启动及通知/锁屏流程检查。真机厂商省电策略需用户手机体验，不以模拟器替代真机结论。

版本统一为 1.5.0。按仓库要求，同一 GitHub Release 同时构建与验证 Windows x64、macOS arm64、macOS x86_64；同时保留既有 Linux 产物。安卓 APK 使用私有保存的发布密钥签名，密钥不提交。保留 Mac 试用版、未 Developer ID 签名及未公证说明。所有必需构建通过才公开发布。
