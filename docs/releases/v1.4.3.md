修复软件先启动、后连接蓝牙耳机时，音频仍绑定旧设备的问题。

- 背景音乐和到时提示音跟随系统默认音频输出切换，支持连接、断开耳机和切换默认设备。
- 保留歌曲进度与播放/暂停状态；切换输出不会自动开始原本暂停的音乐。
- 暂时没有输出设备时等待后续设备变化通知；无关设备通知不重复打开音频输出。
- 新增设备变化回归测试。本机使用实际音频设备验证切换后的暂停进度、继续播放和循环提醒状态。

Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64 及 Ubuntu x86_64 由同一提交构建，通过自动检查后统一发布。

验证边界：自动检查不等同于实际耳机可听声音验证，具体蓝牙硬件连接时序仍需实机体验。
Windows 版本未数字签名；macOS 仍为预览版，未使用 Developer ID 签名或 Apple 公证，首次启动说明见 docs/MACOS.md。
