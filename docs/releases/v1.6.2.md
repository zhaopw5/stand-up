Android 首页为自定义时长增加独立间距，消除相邻预设与透明按钮的拥挤感，保留完整触控范围和山野主题。

- 音乐库统一更名为「背景音乐播放列表」，长标题使用独立整行入口。
- 所有曲目包括内置音乐都可以上移、下移或移除；排序和移除结果在重启后保留。
- 内置音乐仅从播放列表移除，随时可以通过「恢复内置音乐」添加回来；移除歌曲不会删除手机音频文件。
- 调整顺序保留当前曲目和进度。移除当前歌曲时选择相邻歌曲并暂停；移除其他歌曲保留当前播放状态。
- 播放列表为空时关闭播放控制，仍可导入音乐或恢复内置音乐。

支持 Android 8.0 及以上，沿用原签名，可覆盖安装 v1.6.1；保留已有歌曲、播放方式和文件访问授权。
Windows x64、macOS Apple Silicon arm64、macOS Intel x86_64、Ubuntu x86_64 和 Android 在同一版本构建验证后统一发布。桌面功能沿用已发布版本。
Windows 未数字签名；macOS 仍为试用版，未使用 Developer ID 签名或 Apple 公证，首次启动见 docs/MACOS.md。
